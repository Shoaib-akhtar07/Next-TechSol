# MASTER FIGMA DESIGN PROMPT

## Project

Design a complete, production-ready digital ecosystem for a new global software technology company.

The company provides:

* Web application development
* Mobile application development
* SaaS development
* Enterprise software
* API development
* Third-party integrations
* AI solutions
* AI agents and automation
* Cloud and DevOps
* UI/UX design
* Software consulting
* Maintenance and technical support

The company starts as a founder-led technology company but is designed to scale into an international software engineering organization.

The design must communicate:

**Trust + Engineering Excellence + Innovation + Intelligence + Premium Quality + Scalability**

The product must feel like a serious technology company, not a freelancer portfolio, generic software house, template website, or crypto/AI startup.

# 2. DESIGN PERSONALITY

Use a visual language that is:

* Futuristic
* Premium
* Minimal
* Professional
* Enterprise-grade
* Intelligent
* Confident
* Modern
* Clean
* Sophisticated
* Highly usable

Avoid:

* Excessive gradients
* Excessive neon
* Cyberpunk aesthetics
* Gaming-style interfaces
* Cryptocurrency aesthetics
* Excessive glassmorphism
* Generic SaaS templates
* Excessive rounded cards
* Huge meaningless typography
* Decorative elements that reduce usability
* Overly complex dashboards

The interface should look impressive in the first 3 seconds but remain comfortable to use after several hours.

---

# 3. VISUAL DIRECTION

Create a refined dark-first technology aesthetic with a strong light-mode alternative.

Primary visual direction:

* Deep charcoal / near-black foundation
* Neutral surfaces
* High-contrast typography
* One sophisticated brand accent
* Subtle gradients only where they improve hierarchy
* Very subtle borders
* Controlled shadows
* Large negative space
* Strong grid alignment

The design should resemble the quality level of leading modern technology companies and enterprise SaaS products.

Do not copy any existing company's interface.

Use inspiration only from the principles of high-end product design.

The final Figma design must look like a product that could realistically be launched by a serious international technology company.

It must NOT look like:

* A student project
* A generic dashboard template
* A freelancer portfolio
* A crypto startup
* A gaming website
* An AI gimmick
* A collection of unrelated screens

Every screen must have:

* Strong hierarchy
* Consistent spacing
* Consistent components
* Clear CTA
* Realistic content
* Responsive behavior
* Accessible interaction
* Professional information architecture

---

# 54. FINAL DESIGN TEST

Before considering the design complete, verify:

1. Can a new customer understand the company within 10 seconds?
2. Can a customer request a project without contacting support?
3. Can a customer track their project?
4. Can an employee immediately understand today's work?
5. Can a manager assign and monitor tasks?
6. Can an administrator control users and permissions?
7. Can management understand company performance?
8. Can finance manage invoices and payments?
9. Can the system handle documents and files?
10. Can AI assist without creating unsafe automatic changes?
11. Does the system work on desktop and mobile?
12. Are components reusable?
13. Is the design system consistent?
14. Is the interface accessible?
15. Does the entire ecosystem feel like one company?

The final result should communicate:

**"This company knows how to engineer serious software."**

Do not prioritize visual effects over usability.

Prioritize:

**Clarity → Trust → Usability → Scalability → Visual Excellence.**
